# Adesso Design System Rules

- Figma ADS is the visual and component source of truth.
- Do not introduce or change tokens, component variants, states, typography,
  spacing, radii, or iconography without explicit design approval.
- Reuse `@ads/tokens`, `@ads/css`, `@ads/icons`, and `@ads/ui-web`; do not create local
  lookalikes in consuming applications.
- Every visible element added or changed in a consuming application must be
  composed from ADS components, primitives, icons, typography, and semantic
  tokens. For example, input sets must use ADS Input rather than local native
  inputs and application CSS.
- Native controls are allowed only inside `@ads/ui-web` component
  implementations. If ADS has no suitable primitive, stop and request explicit
  approval; do not create a local fallback.
- Keep reusable behavior in focused hooks and presentation in components.
- Hooks may own state, events, keyboard behavior, validation, and accessibility
  logic only. They must not contain colors, spacing, typography, radii, CSS
  classes, or visual variant decisions.
- Every approved new component behavior must be implemented as a focused hook,
  such as `useInputState` or `useDropdownKeyboardNavigation`, and then composed
  by the presentation component.
- An approved new component, token, state, or variant must be represented in
  Figma, `ads.config.json`, its ADS package, tests, and documentation before a
  consuming application may use it.
- Treat focus and pressed states as runtime behavior, filled state as derived
  from the input value, disabled state as the native `disabled` attribute, and
  error state as derived from `errorMessage`.
- Every icon-only control must have an accessible name.
- The repository Git hook must pass before committing; do not bypass it with
  `--no-verify`.
- `packages/tokens/src/figma.tokens.json` is the raw Figma export. Files under
  `packages/tokens/src/generated/` are generated by `npm run tokens:build` and
  must never be edited manually.
- Files under `packages/icons/src/figma/` are the raw Figma icon export. Files
  under `packages/icons/src/generated/` are generated by `npm run icons:build`
  and must never be edited manually or replaced with visually similar SVGs.
- Code Connect templates under `code-connect/icons/` are generated by
  `npm run code-connect:build` and must not be edited manually. Every published
  ADS component should have a parserless `.figma.ts` template using
  `figma.code`; never create `.figma.tsx` mappings.
- Run `npm run check` before handing off changes.
